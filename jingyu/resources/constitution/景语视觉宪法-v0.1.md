# 景语视觉宪法 v0.1（草案）

> **文档状态**：草案，待 Norna 审定。非规范性创作参考：不是引擎合同、自动质量
> 门禁或普适审美定律；不遵守不会触发任何处罚或功能限制。文本许可待定。
>
> **性质**：面向人类创作者、通用 AI 与景语创作工作流的视觉原则。

> **它不负责证明一张图为何正确。**
>
> Workflow 负责保存事实、约束修订、复核画面与保存分支；本宪法只负责两件事：
> 让一张图先作为一个整体成立，并保护那些不应在推理开始以前就被杀死的可能。
>
> **一切景语，皆情语。**（王国维《人间词话》）
>
> **先有整体，后有局部；一切判断最终必须回到眼睛。**

## 0. 使用说明

本宪法不是构图教程、色彩手册、摄影技法或风格配方。

三分法、互补色、焦段选择、布光方案、某种画风的具体做法，都可以拥有各自的参考手册、判例与机器检查；它们只在一部分画面中成立，不上升为宪法。

宪法只写三类东西：

- **什么让一张图成为一个整体；**
- **什么一旦立下，就开始约束后来的一切；**
- **什么值得在每一轮都被重新追问。**

每章末尾的「追问」是本宪法最主要的用法：条款用来提出问题，而不是直接给出答案。

### J0｜元原则

* **J0.01｜创作空间**：宪法首先保护可能性，不以减少可能性证明自身有效。
* **J0.02｜程序分权**：事实一致性、修订范围、版本关系、证据与分支由 Workflow 管辖；宪法不建立第二套程序。
* **J0.03｜规则退位**：能由引擎、Schema、几何检测或渲染自检确定的问题，如穿模、悬空、出画、资产缺失、渲染噪点，交给机器检查，不升级为审美法。
* **J0.04｜看图终审**：文字、理论、指标、推导与条款只提供观察方式；稳定、可复现的视觉差异拥有最终裁决权。
* **J0.05｜意图非结果**：场景描述里写着“暖光”，不等于画面是暖的。判断只看渲染出的图像，不看自己的描述与意图。
* **J0.06｜理由非证据**：一项选择能被漂亮地解释，不构成它在画面中成立的证据。
* **J0.07｜多解合法**：同一需求可以有多个彼此不能替代的完整画面。
* **J0.08｜未知保护**：没有现成名称、流派或判例的视觉关系，不因此地位更低。
* **J0.09｜技术诚实**：无意的穿插、漂浮、比例错乱、透视错误、噪点与破图，不得借“风格”之名逃避；有意越界须明确成为作品的一部分。
* **J0.10｜例外常在**：任何下位原则都可以被作品自身推翻；推翻后作品明显更成立，原则应退让。
* **J0.11｜反平均化**：不得为了满足更多条款，把鲜明的选择磨成安全、正确、无人格的中间值。
* **J0.12｜跨端成立**：本宪法的每一条，都应同时适用于写实照片、风格绘画与抽象构成；只在某一端成立的规则，属于风格参考，不属于宪法。

# J1｜统摄：整体先于局部

眼睛先看见一张图，然后才看见图里的东西。

第一瞥读到的不是物体，而是**分布**：明暗落在哪里，色彩倾向何方，细节聚在何处，边缘哪里硬、哪里软。

一张图最常见的失败，不是某个细节画错了，而是这些分布彼此不属于同一个世界。

**细节救不了整体；整体一旦成立，细节只需不背叛它。**

* **J1.01｜整体先读**：画面先作为一个整体被感知；任何局部的价值，都要回到它在整体中的位置判断。
* **J1.02｜分布先于个体**：先审明暗、色彩、细节密度、边缘与注意力在画面上的分布，再审单个物体是否正确。
* **J1.03｜统一来自同源**：画面的统一不来自各部分长得相像，而来自它们服从同样的来源：同一种光，同一片空气，同一只镜头，同一只手，同一份情。
* **J1.04｜异物追因**：某处“不属于这张图”时，先问它违背了哪一个共同来源，而不是先去修它的细节。
* **J1.05｜生成器不包办**：再完善的生成器也只给出物理上的同源（三维场景天然统一了光源、镜头与空间）；同一只手、同一种注意、同一份情不会自动出现，必须被立下。
* **J1.06｜由大到小**：先定大关系，再定中间层，最后才是细节与纹理。大关系未定时精修细节，是在沙上盖楼。
* **J1.07｜起点可小，裁决在大**：一张图可以从一个细节、一块颜色或一次偶然出发；但它能否留下，要回到整体裁决。
* **J1.08｜细节可伤整体**：过锐、过密、过亮或出自另一只手的细节，会从整体中跳出来；细节首先要做到不背叛。
* **J1.09｜局部改动回全局**：每一次局部修改后，都要重新看整张图；局部更好而整体变差，这次修改不成立。

> **追问**：缩到拇指大小时，这张图还在说它想说的话吗？哪一处不属于这个世界？它违背的是光、空气、镜头、手，还是情？

# J2｜层级与特权

处处用力，等于处处无力。

画面里最强的明暗对比、最锐利的边缘、最饱和的颜色、最密的细节、最亮的一点，都是**特权**。特权是稀缺的：给了一处，别处就要让。

注意力的层级不是价值的等级。后景不比前景卑微，只是处在不同的感知位置。

* **J2.01｜特权稀缺**：最强的对比、最锐的边缘、最高的饱和、最密的细节，应被有意分配，而不是平均撒满。
* **J2.02｜均匀需要理由**：所有区域同样清晰、同样鲜艳、同样精细，通常是失序；若均匀满铺本身就是作品的身份，它合法。
* **J2.03｜焦点可单可多**：单一焦点适合很多画面，但不是普遍义务；多中心、漫游式观看与无焦点构成同样合法。
* **J2.04｜位置非价值**：前景、中景、背景描述的是感知位置，不是重要程度。
* **J2.05｜背景有生**：背景可以有自己的形状、节奏与变化，不必只是一块衬布；背景若持续抢夺注意，应承认它已经升格。
* **J2.06｜空白有权**：没有被占据的区域不是缺陷，不因“空着”便自动填充。
* **J2.07｜边框属于作品**：画框切在哪里、什么被切到画外、画外暗示了什么，都是画面的一部分。
* **J2.08｜视线有路**：眼睛进入、停留、离开画面的方式是结构的一部分；路可以清楚，也可以迂回，但不应无意间被堵死或被引出画外。

> **追问**：眼睛第一下落在哪里？那是你想让它落的地方吗？特权都给了谁，有没有浪费在不重要的地方？哪里因为害怕空着而被填满了？

# J3｜关系：一切都是相对的

画面里没有绝对正确的明暗、颜色或清晰度。

一块灰在暗处显得亮，在亮处显得暗；一种颜色的冷暖取决于它旁边是什么；一条边的锐利，取决于其他边有多软。

**改一处，就是改全部。**

* **J3.01｜明暗是关系**：没有正确的亮度，只有正确的明暗关系。
* **J3.02｜色是关系**：颜色在邻色、光色与整体色调中被感知；单独看正确的颜色，放进画面可能是错的。
* **J3.03｜清晰是关系**：锐利与模糊互相定义；全部锐利，等于没有锐利。
* **J3.04｜尺度是关系**：大小、远近与轻重由画面内部的参照建立；参照一旦建立，所有形都要服从它，有意违背须成为作品的一部分。
* **J3.05｜交界最诚实**：形与形、形与光、形与空气的交界处，最容易暴露某样东西不属于同一世界；审查可信度时，先看交界。
* **J3.06｜调整看连带**：修改任何一个关系后，检查它还牵动了哪些关系。

> **追问**：这块颜色在整张图里读起来是什么，而不是单独看是什么？哪一条交界让人觉得是“贴上去的”？

# J4｜可信：自洽即真

逼真只是可信的一种。

一张风格化的画可以比一张照片更可信，只要它的世界有自己的规则，并且处处遵守。可信来自**自洽**：光有一套逻辑，形有一种造法，笔出自一只手。

* **J4.01｜可信先于逼真**：画面首先要在自己的规则里成立；逼真只是“规则即物理世界”时的特例。
* **J4.02｜规则一立便有后果**：画面一旦建立了光的逻辑、空间的逻辑与造型的方式，后来的每一个元素都要服从，或者明确地、有意地打破。
* **J4.03｜风格是一只手**：风格不是一组元素清单，而是一种贯穿全画的变换方式；同一只手画出的天空、人物与石头，才属于同一张画。
* **J4.04｜混手须自觉**：写实物件出现在卡通世界里，或多种手法并置，都可以成立；但它必须是有意的异质，而不是素材来源不同造成的意外。
* **J4.05｜物理可违，自洽难违**：风格化可以违背物理，却不能违背它自己立下的规则。
* **J4.06｜重量与接触**：形如何落地、倚靠、遮挡与相接，决定它是否真的在这个世界里；这对写实、风格化与抽象画面同样成立。

> **追问**：这张图的世界规则是什么？有哪一处在用另一套规则说话？如果拿掉所有纹理，只剩形与光，它还可信吗？

# J5｜情：一切景语皆情语

景语不是在风景上贴情绪标签。

情不在某个物件里，而在光的角度、色的冷暖、距离的远近、空间的开合、时间的早晚里。

**同一张桌子，换一种光，就是另一种心情。**

* **J5.01｜情在关系，不在物件**：情绪主要由光、色、距离、空间、时间与节奏承载，而不是由添加带象征意味的道具承载。
* **J5.02｜反符号化**：枯树不等于悲伤，樱花不等于日本，夕阳不等于怀旧；单个符号代替不了完整的情境。
* **J5.03｜情有统摄**：一张图可以有复杂、矛盾、未决的情感，但应有一股力量把它们收在同一张画里。
* **J5.04｜不必说破**：画面可以留有余地，让观者自己走完最后一步；情写得太满，反而失了味。
* **J5.05｜冷静也是情**：客观、克制、说明性的画面同样是一种立场，不必强行“有氛围”。
* **J5.06｜名称不绑风格**：“景语”之名出自中国诗论，但不要求画面呈现任何特定文化外观；它约束的是如何看待景与情的关系。

> **追问**：不看标题和描述，这张图让人感到什么？这份感受来自关系，还是来自一个被放进去的符号？哪里说得太满了？

# J6｜萌发、迭代与一致

一张图不是先有全部理由再被画出来的。偶然的渲染结果、一次失手的光、一个没打算要的角度，都可能成为作品的起点。

但画面一旦立下了身份，后来的每一次迭代都应记得它。

**迭代的敌人不是变化，而是无因的漂移。**

* **J6.01｜种子先行**：材料可以先于理由出现；偶然、直觉与试探都可以进入候选。
* **J6.02｜偶然不免审**：偶然只给材料进入候选的资格，不给它永久保留的权利。
* **J6.03｜先指后名**：感到不对时，先指出位置，再寻找原因；说不出原因，不妨碍指出位置。
* **J6.04｜身份有核**：每张图或每组图都应知道什么不能变、什么可以变；这由画面宪章写明，本宪法不代写。
* **J6.05｜漂移不是变化**：迭代之间、系列之间的每一处差异，都应能追到一个原因（时间变了、镜头动了、作出了新的决定）；追不到原因的差异是漂移。
* **J6.06｜改动有尺度**：动了大关系、身份核或世界规则的修改，已经不是精修，应回到正式修订。
* **J6.07｜无事不迭代**：没有真实的问题、冲突或新可能时，不为了显得认真而继续修改。
* **J6.08｜分支自立，不求平均**：两个方向都成立时，可以分成两张完整的画；不得把它们折中成一个双方都失去锋芒的版本。
* **J6.09｜完成看收益**：当新的修改不再稳定地让画面更成立，就应怀疑继续迭代的必要；完成不等于没有问题。
* **J6.10｜保留锋芒**：最后阶段尤其警惕：为了修平局部异常，而抹掉这张图的独特之处。

> **追问**：和上一版相比，每一处变化都有原因吗？这一轮修改在解决问题，还是在制造平均？

# J7｜看审与 Agent

宪法的最后任务不是告诉创作者该改什么，而是让一张已经能自圆其说的图，仍有机会暴露语言和推理没有发现的问题。

## J7.1｜五种看法

每一轮重要复核，至少用五种方式看同一张图。它们不必形成分数。

**一、一瞥看**：只看一眼，或缩小、翻转以后再看。第一眼看见了什么？整张图在说什么？和画面宪章的承诺一致吗？

**二、眯眼看**：模糊掉全部细节，只看大的明暗与色块。没有细节时，结构还站得住吗？有没有本该退后的地方在往前冲？

**三、黑白看**：去掉颜色，只看明暗。明暗层级清楚吗？颜色是不是在替明暗掩盖问题？

**四、减法看**：隐藏一个可疑元素再看。拿掉以后，什么真正失去了？如果什么都没失去，它为什么还占着位置？

**五、并置看**：与上一版、与同组的其他画面并排看。哪些变化是有意的，哪些是漂移？整组还像出自同一只手、同一个世界吗？

## J7.2｜评价分离

* **J7.2.01｜结构与质感分审**：大关系是否成立，与质感是否精美，分开判断；精美的质感不能替空洞的结构作答。
* **J7.2.02｜整体不赦技术错误**：整体氛围再好，也不能掩盖真实的技术失败。
* **J7.2.03｜局部不绑整体**：某个元素单独看不好看，不证明它在整体里没有价值。
* **J7.2.04｜不适即线索**：稳定的不适感是证据，即便说不出原因；用对比、减法与定位去找到它，而不是忽略它。
* **J7.2.05｜先差异后价值**：两个版本的差异无法被稳定看出时，不急于为差异建立审美理论。

## J7.3｜Agent

* **J7.3.01｜条款生成问题**：Agent 用宪法提出问题，而不是用条款直接生成答案。
* **J7.3.02｜条款不是理由**：“因为 Jx.xx 如此要求”不是视觉选择的充分依据。
* **J7.3.03｜区分四物**：区分事实（画面里看得见的）、假设、解释与判断，不以其一冒充其他。
* **J7.3.04｜不吃均值**：训练数据中最常见的画面只是分布的均值，不天然拥有更高的合法性；居中构图、处处精致、过度饱和与泛光，常常只是均值的样子。
* **J7.3.05｜不造冲突，不造必然**：没有真实疑问时，不为了走完流程虚构方案；多个方向都能成立时，承认不确定或进入分支。
* **J7.3.06｜越流畅越警惕**：能把一个选择解释得非常流畅时，更要检查这个解释是否真的指向画面里的事实。
* **J7.3.07｜先看后说**：先描述看到了什么变化，再解释为什么；不得先有理论，再逼眼睛去找证据。

# 附录 A｜不属于宪法的内容去向

| 内容 | 去向 |
| --- | --- |
| 构图法则、色彩方案、镜头焦段、布光方案 | 风格参考与判例库 |
| 某一画风的具体做法（描边粗细、色阶数量、笔触形态） | 风格预设 |
| 穿模、悬空、出画、遮挡、比例、渲染噪点 | 机器检查（hard failure） |
| 单张或单组图的承诺、身份核、可变与不可变 | 画面宪章（Workflow） |
| 修订范围、版本、证据、分支 | Workflow |

宪法只保留这些系统替代不了的事：

> 什么让一张图成为一个整体。<br>
> 什么一旦立下，就开始约束后来的一切。<br>
> 什么值得在每一轮被重新追问。<br>
> 以及什么时候，应该停止解释，重新去看。

# 附录 B｜五种看法与工具（建议，非正文）

五种看法都可以由工具直接提供视图，让有视觉能力的模型不必靠想象去“眯眼”：

| 看法 | 工具提供的视图 |
| --- | --- |
| 一瞥看 | 缩略图、水平翻转 |
| 眯眼看 | 模糊图、极低分辨率图 |
| 黑白看 | 亮度通道、明暗分级图 |
| 减法看 | 按物体 ID 隐藏后重新渲染 |
| 并置看 | 候选并排、差异图 |

# 修宪纪律

* 一项规则若能被技术检查精确替代，应从宪法删除。
* 一项规则若只在某类风格或某类画面中成立，应降为风格参考或判例（跨端检验）。
* 一项规则若不能转写成一个值得追问的问题，应重新审视它的写法。
* 每次新增限制，都必须同时说明它保护了什么，以及它可能杀死什么。
* 每次修宪保留旧版本；旧作品不因新宪法出现而被追溯判错。
* 宪法的成熟，不以条款越来越多衡量，而以越来越少的条款仍能统摄越来越多样的画面衡量。

> **制定原则**
>
> **先看整体，再问关系。**
>
> **允许它先发生；当世界立起来，再追问为何如此。**
>
> **而在所有解释之外，给那些说不出名字、却让画面真正活起来的东西，留一个位置。**
