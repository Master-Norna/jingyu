## `get_guide`

Start here: what Jingyu is, the recommended workflow, conventions and the tool list.

无参数。

返回字段：`workflow`、`conventions`。

## `get_scene_schema`

The JSON Schema of a scene description, a minimal valid example and the conventions.

无参数。

返回字段：`schema_id`、`json_schema`、`example`。

## `list_generators`

The primitive catalogue: every geometry operator, material family and environment family (the light around the scene: daylight, uniform) with its parameters, units, ranges, defaults and examples.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `kind` | all / geometry / materials / environments | `"all"` |  |

## `validate_scene`

Check a scene description without rendering. Returns every issue with a JSON Pointer and a hint, and the scene's content hash when valid.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `scene` | object |  | The scene description (jingyu.scene.v1). |
| `scene_path` | string |  | Path of a scene JSON file inside the workspace. |
| `from_candidate` | string |  | Id of a candidate whose scene to use (the scene it was rendered from). |
| `include_normalized` | boolean | `false` | Also return the scene with every default filled in. |

以下参数恰好给出一组：`scene`；`scene_path`；`from_candidate`。

返回字段：`valid`、`issues`、`scene_sha256`、`normalized`。

## `edit_scene`

Change a scene without rewriting it: JSON Patch operations (add, remove, replace, move, copy, test) plus merge (merge an object into the value at path). A path segment @<id> selects an array element by id, e.g. /objects/@bowl/location or /groups/@still_life/location. Returns the edited scene with validation issues; save_as writes it to a workspace file. To move several things together, give them a group and edit the group.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `scene` | object |  | The scene description (jingyu.scene.v1). |
| `scene_path` | string |  | Path of a scene JSON file inside the workspace. |
| `from_candidate` | string |  | Id of a candidate whose scene to use (the scene it was rendered from). |
| `operations` * | array of object |  |  |
| `save_as` | string |  | Workspace path to write the edited scene to. |

以下参数恰好给出一组：`scene`；`scene_path`；`from_candidate`。

返回字段：`valid`、`issues`、`scene_sha256`、`scene`、`saved_to`。

## `frame_subject`

Say where things should sit in the frame and how big, and get the camera that does it: subject (object or group ids; an object brings what is parented to it), at (where the centre of the subject's box goes, u from the left and v from the top), size (the share of the frame it spans). The camera keeps the direction it sees the subject from unless azimuth/elevation are given, keeps its lens and solves its distance (or keeps distance and solves lens_mm). Returns the camera, edit_scene operations, the edited scene, where every object would land in the frame, and warnings (the camera inside a wall, something hiding the subject). Nothing is rendered.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `scene` | object |  | The scene description (jingyu.scene.v1). |
| `scene_path` | string |  | Path of a scene JSON file inside the workspace. |
| `from_candidate` | string |  | Id of a candidate whose scene to use (the scene it was rendered from). |
| `subject` * | array of string |  | Object or group ids to frame together. |
| `at` | object |  | Where the subject's centre goes; default the middle. |
| `size` | number > 0, <= 4 | `0.5` | Share of the frame the subject spans (1 = edge to edge). |
| `size_of` | larger / width / height | `"larger"` | Which extent size measures: the larger of the two, or the width or the height of the subject's box. |
| `camera` | string |  | Camera id; default the render camera. |
| `azimuth` | number |  | Direction from the subject toward the camera, degrees counter-clockwise from +X seen from above; default: as now. |
| `elevation` | number >= -90, <= 90 |  | How high the camera looks down on the subject, degrees; default: as now. |
| `lens_mm` | number > 0 |  | Use this focal length and solve the distance. |
| `distance` | number > 0 |  | Stay this far from the subject's centre and solve the lens. |
| `save_as` | string |  | Workspace path to write the edited scene to. |

以下参数恰好给出一组：`scene`；`scene_path`；`from_candidate`。

返回字段：`operations`、`warnings`、`valid`、`issues`、`scene_sha256`、`scene`、`saved_to`、`camera`、`subject`、`frame`。

## `aim_sun`

Say where sunlight should land and get the sun elevation and azimuth that put it there: target is a world point, an object (its top) or a spot of the frame (uv). Indoors the sun is aimed through an opening (through: a wall and its opening, or any opening when omitted); fix elevation (time of day) or azimuth and the other is searched. Every direction is checked for shadows on the way. Returns the angles, edit_scene operations, the edited scene, the span of angles that still pass the opening, and where the patch of sunlight falls (objects and frame boxes). Nothing is rendered.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `scene` | object |  | The scene description (jingyu.scene.v1). |
| `scene_path` | string |  | Path of a scene JSON file inside the workspace. |
| `from_candidate` | string |  | Id of a candidate whose scene to use (the scene it was rendered from). |
| `target` * | object |  | Where the sunlight must land: one of point, object or uv. |
| `through` | object |  |  |
| `elevation` | number >= -10, <= 90 |  | Keep the sun this high and solve the azimuth. |
| `azimuth` | number |  | Keep the sun in this direction and solve the elevation. |
| `light` | string |  | environment.sun (default with daylight) or a sun light id. |
| `save_as` | string |  | Workspace path to write the edited scene to. |

以下参数恰好给出一组：`scene`；`scene_path`；`from_candidate`。

返回字段：`operations`、`warnings`、`valid`、`issues`、`scene_sha256`、`scene`、`saved_to`、`light`、`sun`、`target`、`through`、`patch`。

## `view_candidate`

Look at a candidate one of several ways: full, glance, flip, squint, grayscale, values, saturation, light (where one light lands), id_mask, or compare (beside other_candidate_id). Give region to crop and enlarge any view except glance and compare, to inspect a detail.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `candidate_id` * | string |  | A candidate id such as c_20260926T120000Z_1a2b3c4d_5e6f. |
| `view` * | full / glance / flip / squint / grayscale / values / saturation / light / id_mask / compare |  | Which view. |
| `max_size` | integer >= 64, <= 4096 | `1024` |  |
| `levels` | integer >= 2, <= 16 | `5` | Value steps for the values view. |
| `other_candidate_id` | string |  | A candidate id such as c_20260926T120000Z_1a2b3c4d_5e6f. |
| `light` | string |  | Light id for the light view (environment.sun for the sun). |
| `region` | object |  | Pixel box x0/y0/x1/y1 (x1, y1 exclusive) or normalised u0/v0/u1/v1. |

返回字段：`candidate_id`、`view`、`description`、`width`、`height`、`meta`。

## `locate_in_candidate`

Point at the image and get the scene back: the object, its material and the JSON Pointers to edit, from the candidate's exact id mask. Also returns the colour actually rendered there beside the material's own colour (so drift from warm light or the view transform is visible) and which lights reach the spot directly. Where the image shows the world behind everything (sky, ground), it says so, and names the opening (a window in a wall) the eye looks through.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `candidate_id` * | string |  | A candidate id such as c_20260926T120000Z_1a2b3c4d_5e6f. |
| `point` | object |  | Pixel x/y from the top-left, or normalised u/v in [0, 1]. |
| `region` | object |  | Pixel box x0/y0/x1/y1 (x1, y1 exclusive) or normalised u0/v0/u1/v1. |
| `radius` | integer >= 0, <= 64 | `3` | Neighbourhood radius in pixels for point queries. |

以下参数恰好给出一组：`point`；`region`。

返回字段：`candidate_id`、`mode`、`result`。

返回字段：`candidate_id`、`lights`、`objects`、`shadows`、`in_view`、`openness`。
