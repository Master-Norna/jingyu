# 画风深度审查（代码层面的第一轮）

目标从“增加选项数量”转到**不同媒材的内部结构是否可信、可控、可复现**。以下是从当前实现得出的风险及后续验收点，并非作品级视觉评审的结论。所有样式共享透明度、强度混合、输入不变性与固定种子回归。

| 画法 | 需深化的主要结构 | 可验证方向 |
| --- | --- | --- |
| ink | 轮廓粗细和次要阴影线仍相近 | 主次线宽、轮廓闭合、区域外不串线 |
| watercolor | 等亮度不同色相的边界未积色 | 色相分界上的积色与受控扩散（本轮） |
| oil | 原先只有保边平滑，没有独立实体笔触 | 随光照转向的笔痕、区域内不跨色（本轮） |
| cel | 亮度色阶和边缘厚度较机械 | 面内阴影分块、轮廓主次线 |
| charcoal | 整块灰度较均匀 | 擦抹方向、颗粒与压痕层次 |
| woodcut | 刻线贯穿且全图同角度 | 局部刀痕方向、刻刀留白 |
| pencil | 规则交叉排线缺少压力变化 | 线宽/硬度分级、边缘跟随 |
| stippling | 网格分点易有周期性 | 密度恒定时的不聚集性、渐变连续性 |
| gouache | 主要是滤波和量化色面 | 平涂刷痕、干湿边界、覆盖不透明性 |
| pastel | 短笔刷方向较随机 | 纸齿颗粒、顺形揉擦与叠色 |
| etching | 多种规则刻线并列 | 区域方向、交叉角度与留白 |
| mosaic | 中心像素不能代表整片色彩 | 小对象贡献到拼片均值（本轮） |
| crayon | 只使用两层短划线 | 蜡层叠压、缺墨间断与纸纹遮挡 |
| screenprint | 固定色版和均匀网点 | 独立色版偏移、叠色和套准 |
| papercut | 色彩量化不总是空间连通 | 色区形状连续性、投影顺序 |
| sumi | 同方向笔痕和分级水洗 | 墨色浸染、笔锋压力和留白 |
| stainedglass | 色板碎片可能太细 | 连通玻璃片尺度、封闭铅条 |
| cyanotype | 以亮度重映射模拟感光 | 接触印边缘与自然曝光过渡 |
| frottage | 暗部摩擦浓淡已能变化 | 接触高低、纹理方向和纸齿 |
| embroidery | 单格一条彩线 | 丝线走向、层叠针法与布底 |
| glaze | 釉料与高光仍依赖规则采样 | 积釉厚度、釉色渐变、反光聚集 |

## 本轮公共基础

- 纸张的细纹与大块纹理都保留固定屏幕空间尺度；调整画布大小不改变同坐标处的纸纹。对正方形与长宽比较大的场景都一致。
- `paper=0` 的共用纹理实现直接返回中性白蒙版，避免无意义的噪声生成。
- 将全部 21 种预设纳入输入不变性、RGBA alpha 和确定性回归；再对每次实际改动添加针对性机制测试。

## 第二轮：线条家族的方向与压力

- 铅笔与蚀刻：以局部亮度梯度的切线代替贯穿全图的固定斜线，线段长度与着墨压力由固定种子略作变化，深阴影再增加另一方向的交叉排线。
- 木刻：暗块中真正挖出有方向的留白刻痕，而不是只在黑色底上继续叠黑线。
- 水墨：将机械等方向短线改为局部顺形、两段宽度与墨量递减的收锋笔触。
- 所有新笔触均使用局部像素梯度和整型散列，不依赖随机全局状态；结果可跨调用复现，保留场景 Schema、RGBA 与强度契约。
- 仍存在的局限：屏幕空间梯度不等于物体表面切线；大面积平坦区域采取斜向默认值，艺术风格与物理笔法还需真实作品评估。

## 后续分批

1. **线条家族**：ink、cel、pencil、charcoal、woodcut、etching、stippling、sumi；重点是方向、压力、密度与留白。
2. **颜料家族**：watercolor、oil、gouache、pastel、crayon、glaze；重点是覆盖关系、积色、颗粒与笔触。
3. **构成与印刷家族**：mosaic、screenprint、papercut、stainedglass、cyanotype、frottage、embroidery；重点是区域划分、连通性、材质边界与投影。

**工程全绿不等于艺术效果合格。** 在集中做作品之前，先把每种画法的可测结构完善，再用同一场景做视觉对照。
