# 生成器目录

景语收集的是生成器，不是资产：形状来自几何算子，表面来自材质族，每个都是带参数的
原语。差异再小，也只是参数值不同。带 `*` 的参数必填，其余有默认值。单位：长度米、
角度度，其他单位写在字段名后缀里。

## 几何算子（`geometry.op`）

### `box`

Axis-aligned box standing on its origin.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `size` * | array of number |  | Width (x), depth (y) and height (z) in metres. |

示例：`{"op": "box", "size": [1.2, 0.6, 0.75]}`

### `plane`

Flat rectangle in the XY plane, centred on its origin, facing +Z.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `size` * | array of number |  | Width (x) and depth (y) in metres. |

示例：`{"op": "plane", "size": [20, 20]}`

### `sphere`

UV sphere resting on its origin (its lowest point).

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `radius` * | number > 0 |  | Radius in metres. |
| `segments` | integer >= 3, <= 1024 | `64` | Number of segments around the axis; more is smoother and heavier. |
| `rings` | integer >= 2, <= 512 | `32` | Number of rings from pole to pole. |

示例：`{"op": "sphere", "radius": 0.1}`

### `cylinder`

Closed cylinder standing on its origin.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `radius` * | number > 0 |  | Radius in metres. |
| `height` * | number > 0 |  | Height in metres. |
| `segments` | integer >= 3, <= 1024 | `64` | Number of segments around the axis; more is smoother and heavier. |

示例：`{"op": "cylinder", "radius": 0.05, "height": 0.2}`

### `cone`

Cone or truncated cone standing on its origin.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `radius` * | number > 0 |  | Bottom radius in metres. |
| `height` * | number > 0 |  | Height in metres. |
| `top_radius` | number >= 0 | `0.0` | Top radius in metres; 0 makes a point. |
| `segments` | integer >= 3, <= 1024 | `64` | Number of segments around the axis; more is smoother and heavier. |

示例：`{"op": "cone", "radius": 0.1, "height": 0.3}`

### `lathe`

Revolve an (r, z) profile around the Z axis. thickness 0 makes a solid; thickness > 0 makes an open-topped shell with a closed floor.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `profile` * | array of array |  | Points [r, z] in metres from the bottom outer edge upward. r >= 0. A solid is closed to the axis automatically at both ends. |
| `thickness` | number >= 0 | `0.0` | Wall thickness in metres; 0 for a solid. |
| `segments` | integer >= 3, <= 1024 | `64` | Number of segments around the axis; more is smoother and heavier. |
| `sharp_angle` | number >= 0.0, <= 180.0 | `30.0` | Profile corners turning more than this many degrees are shaded crisply. |

示例：`{"op": "lathe", "profile": [[0.04, 0], [0.05, 0.08], [0.045, 0.1]], "thickness": 0.003}`

### `vessel`

Parametric vessel family (cup, bowl, vase, bottle, jar, pot): a lathe whose outer wall passes smoothly through base, belly, neck and lip rings.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `height` | number > 0 | `0.25` | Total height in metres. |
| `base_radius` | number > 0 | `0.05` | Radius at the foot, metres. |
| `belly_radius` | number > 0 | `0.08` | Radius at the belly, metres. |
| `belly_at` | number > 0, <= 1 | `0.4` | Height of the belly as a fraction of the height. |
| `neck_radius` | number > 0 | `0.035` | Radius at the neck, metres. |
| `neck_at` | number > 0, <= 1 | `0.8` | Height of the neck as a fraction of the height. |
| `lip_radius` | number > 0 | `0.045` | Radius at the rim, metres. |
| `thickness` | number > 0 | `0.004` | Wall and floor thickness in metres (open vessels only). |
| `open` | boolean | `true` | true: hollow with an open top; false: a closed solid. |
| `segments` | integer >= 3, <= 1024 | `96` | Number of segments around the axis. |
| `profile_samples` | integer >= 4, <= 1024 | `64` | Number of points sampled along the wall. |
| `sharp_angle` | number >= 0.0, <= 180.0 | `30.0` | Profile corners turning more than this many degrees are shaded crisply. |

示例：`{"op": "vessel", "height": 0.1, "base_radius": 0.032, "belly_radius": 0.037, "belly_at": 0.5, "neck_radius": 0.041, "neck_at": 0.9, "lip_radius": 0.042}`

示例：`{"op": "vessel", "height": 0.3, "base_radius": 0.035, "belly_radius": 0.036, "belly_at": 0.55, "neck_radius": 0.012, "neck_at": 0.8, "lip_radius": 0.013}`

## 材质族（`material.family`）

### `ceramic`

Fired clay: matte bisque (gloss 0) to a glassy glaze (gloss 1).

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `color` | string | `"#f2efe8"` | Body or glaze colour. sRGB hex #rrggbb. |
| `gloss` | number >= 0.0, <= 1.0 | `0.8` | Glaze gloss from matte (0) to mirror-like (1). |

示例：`{"family": "ceramic", "color": "#6f93b3", "gloss": 0.9}`

### `glass`

Transparent refractive glass, clear or tinted, polished or frosted.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `tint` | string | `"#ffffff"` | Transmitted colour; white is clear. sRGB hex #rrggbb. |
| `frost` | number >= 0.0, <= 1.0 | `0.0` | Surface frosting from polished (0) to heavily frosted (1). |
| `ior` | number >= 1.0, <= 4.0 | `1.5` | Index of refraction. |

示例：`{"family": "glass", "tint": "#cfe8d4"}`

### `metal`

Conductive metal with measured reflectance, from brushed-dull to mirror-polished.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `metal` | aluminum / brass / chrome / copper / gold / iron / nickel / silver / titanium | `"silver"` | Which metal; sets the physically measured reflectance colour. |
| `polish` | number >= 0.0, <= 1.0 | `0.8` | From dull (0) to mirror-polished (1). |

示例：`{"family": "metal", "metal": "copper", "polish": 0.5}`

### `plastic`

Opaque dielectric such as plastic, paint or plaster, matte to glossy.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `color` | string | `"#d0d0d0"` | Surface colour. sRGB hex #rrggbb. |
| `gloss` | number >= 0.0, <= 1.0 | `0.3` | From matte (0) to glossy (1). |

示例：`{"family": "plastic", "color": "#e8e4dc", "gloss": 0.1}`

### `principled`

Direct physically based parameters; the escape hatch when no family fits.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `base_color` | string | `"#bfbfbf"` | Surface colour. sRGB hex #rrggbb. |
| `metallic` | number >= 0.0, <= 1.0 | `0.0` | 0 dielectric, 1 metal. |
| `roughness` | number >= 0.0, <= 1.0 | `0.5` | 0 mirror-smooth, 1 fully diffuse. |
| `ior` | number >= 1.0, <= 4.0 | `1.5` | Index of refraction. |
| `transmission` | number >= 0.0, <= 1.0 | `0.0` | 0 opaque, 1 fully transmissive (glass-like). |
| `coat_weight` | number >= 0.0, <= 1.0 | `0.0` | Strength of a clear coat layer. |
| `coat_roughness` | number >= 0.0, <= 1.0 | `0.03` | Roughness of the clear coat. |
| `emission_color` | string | `"#ffffff"` | Emitted light colour. sRGB hex #rrggbb. |
| `emission_strength` | number >= 0.0 | `0.0` | Emitted radiance multiplier; 0 emits nothing. |
| `alpha` | number >= 0.0, <= 1.0 | `1.0` | Opacity; 1 is fully opaque. |

示例：`{"family": "principled", "base_color": "#808080", "roughness": 0.4}`
