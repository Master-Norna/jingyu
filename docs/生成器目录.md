# 生成器目录

景语收集的是生成器，不是资产：形状来自几何算子，表面来自材质族，周围的光来自环境族，
每个都是带参数的原语。差异再小，也只是参数值不同。带 `*` 的参数必填，其余有默认值。
单位：长度米、角度度，其他单位写在字段名后缀里。

## 几何算子（`geometry.op`）

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `size` * | array of number |  | Width (x), depth (y) and height (z) in metres. |

示例：`{"op": "box", "size": [1.2, 0.6, 0.75]}`

### `lathe`

Revolve an (r, z) profile around the Z axis. thickness 0 makes a solid; thickness > 0 makes an open-topped shell with a closed floor.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `profile` * | array of array |  | Points [r, z] in metres from the bottom outer edge upward. r >= 0. A solid is closed to the axis automatically at both ends. |
| `thickness` | number >= 0 | `0.0` | Wall thickness in metres; 0 for a solid. |
| `segments` | integer >= 3, <= 1024 | `64` | Number of segments around the axis; more is smoother and heavier. |
| `sharp_angle` | number >= 0.0, <= 180.0 | `30.0` | Profile corners turning more than this many degrees are shaded crisply. |

示例：`{"op": "lathe", "profile": [[0.04, 0], [0.05, 0.08], [0.045, 0.1]], "thickness": 0.003}`

### `vessel`

| `lip_radius` | number > 0 | `0.045` | Radius at the rim, metres. |

示例：`{"op": "vessel", "height": 0.1, "base_radius": 0.032, "belly_radius": 0.037, "belly_at": 0.5, "neck_radius": 0.041, "neck_at": 0.9, "lip_radius": 0.042}`

### `wall`

Upright slab standing on its origin, spanning x, with rectangular openings cut through it (windows, doors). Light passes through the openings.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `size` * | array of number |  | Width (x), thickness (y) and height (z) in metres. |
| `openings` | array of object | `[]` | Rectangular holes through the wall; x is measured from its centre. |

示例：`{"op": "wall", "size": [4.0, 0.15, 2.6], "openings": [{"x": -0.6, "sill": 0.9, "width": 1.2, "height": 1.3}]}`

## 材质族（`material.family`）

|---|---|---|---|

## 环境族（`world.environment.family`）

### `uniform`

The same colour from every direction: a neutral studio or a plain backdrop.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `color` | string | `"#404040"` | Colour of the surrounding light and background. sRGB hex #rrggbb. |
| `strength` | number >= 0.0 | `1.0` | Brightness multiplier. |

示例：`{"family": "uniform", "color": "#d8dde3", "strength": 0.6}`

### `daylight`

Outdoor daylight from dawn to dusk, clear to overcast: a physical sky plus a sun whose direction, colour and softness agree with each other. Light through windows and doors comes from here too.

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `sun_elevation` | number >= -10.0, <= 90.0 | `35.0` | Sun height above the horizon in degrees. 2-10 early morning or late afternoon (long warm light), 25-45 mid-morning, 60+ midday; 0 to -6 is twilight with no direct sun. |
| `sun_azimuth` | number >= -360.0, <= 360.0 | `135.0` | Direction toward the sun in degrees, counter-clockwise from +X seen from above (0 = +X, 90 = +Y, 180 = -X, 270 = -Y). Shadows point the other way. |
| `cloud_cover` | number >= 0.0, <= 1.0 | `0.0` | 0 clear sky with crisp shadows, 0.5 broken clouds, 1 overcast with no direct sun and soft, even light. |
| `haze` | number >= 0.0, <= 10.0 | `1.0` | Aerosols in the air, 0 crystal clear to 10 very hazy; more haze gives a paler sky. |
| `sun_strength` | number >= 0.0, <= 100.0 | `3.0` | Irradiance of the clear-sky sun in W/m^2 (Blender sun strength); clouds and a low sun reduce it automatically. |
| `sun_angle` | number >= 0.0, <= 45.0 | `0.53` | Apparent diameter of the clear-sky sun in degrees; clouds widen it. |
| `sun_temperature_k` | number >= 0.0, <= 25000.0 | `0.0` | Sun colour temperature in kelvin; 0 means automatic, following the elevation (about 2600 K at 5 degrees, 5600 K at 60) and the clouds. |
| `ground_color` | string | `"#6e675c"` | Colour of the land below the horizon, seen through windows and reflected in glossy things (grass, earth, pavement, snow). sRGB hex #rrggbb. |
| `sky_strength` | number >= 0.0, <= 100.0 | `1.0` | Multiplier for light from the sky (blue fill in shadows). |

示例：`{"family": "daylight", "sun_elevation": 12, "sun_azimuth": 200}`
