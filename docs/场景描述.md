# 场景描述（`jingyu.scene.v1`）

场景描述是一张图的唯一事实来源：一个 JSON 文档，写明世界、材质、物体、灯光、相机和
渲染设置。它是声明式的，可以版本化、比较和局部修改；图像里的每个像素都能通过 ID 遮罩
追回到这里的某一条。

完整的机器可读定义是 [`schemas/scene.v1.schema.json`](../schemas/scene.v1.schema.json)
（由生成器注册表生成）；各几何算子和材质族的参数见 [生成器目录](生成器目录.md)。

## 约定

| 项 | 约定 |
|---|---|
| 长度 | 米，字段名不带后缀 |
| 角度 | 度，字段名不带后缀；旋转是 XYZ 欧拉角 |
| 其他单位 | 写进字段名：`power_w`（瓦）、`lens_mm`（毫米）、`sensor_width_mm` |
| 坐标系 | 右手系，Z 向上 |
| 物体原点 | 底面中心：`location` 的 z = 0 就是放在地面上（平面以中心为原点） |
| 颜色 | sRGB 十六进制 `#rrggbb`，进入 Blender 前转换为线性 |
| id | `^[a-z][a-z0-9_-]{0,62}$`，最长 63 个字符（Blender 名字上限） |
| id 命名空间 | 材质一个命名空间；物体、灯光、相机共用一个命名空间 |

未写的可选字段会按 Schema 默认值补全；补全后的“规范化场景”才是渲染和哈希的对象。
未知字段一律拒绝（`additionalProperties: false`），拼错的字段不会被悄悄忽略。

## 顶层结构

```json
{
  "schema": "jingyu.scene.v1",
  "id": "minimal-vase",
  "title": "One vase on a floor",
  "notes": "可选，给人看的说明",
  "world": {"color": "#404040", "strength": 1.0},
  "materials": [ ... ],
  "objects": [ ... ],
  "lights": [ ... ],
  "cameras": [ ... ],
  "render": { ... }
}
```

`schema`、`id`、`cameras`（至少一台）和 `render` 必填。

## 材质

每个材质是一个材质族加参数，`family` 是判别字段：

```json
{"id": "glaze", "family": "ceramic", "color": "#6f93b3", "gloss": 0.9}
{"id": "pot", "family": "metal", "metal": "copper", "polish": 0.72}
{"id": "bottle-glass", "family": "glass", "tint": "#9cd3a8"}
```

现有材质族：`ceramic`、`glass`、`metal`、`plastic`，以及直接写 Principled 通道的
`principled`。材质族的参数是面向创作的（光泽、抛光、磨砂），族内部负责把它们映射成
物理上合理的渲染通道。

## 物体

```json
{
  "id": "vase",
  "geometry": {"op": "vessel", "height": 0.3, "base_radius": 0.045, "belly_radius": 0.085,
               "belly_at": 0.3, "neck_radius": 0.022, "neck_at": 0.9, "lip_radius": 0.03},
  "material": "glaze",
  "location": [0, 0, 0],
  "rotation": [0, 0, 0],
  "scale": [1, 1, 1],
  "visible": true
}
```

`geometry.op` 是判别字段，选择几何算子：`box`、`plane`、`sphere`、`cylinder`、
`cone`、`lathe`（任意旋转体轮廓）、`vessel`（器皿）。省略 `material` 时用中性灰。
`visible: false` 让物体留在场景里但不参与渲染。

## 灯光

`kind` 是判别字段：

| kind | 专有参数 |
|---|---|
| `point` | `power_w`、`radius` |
| `spot` | `power_w`、`radius`、`spot_size`、`blend` |
| `area` | `power_w`、`size` |
| `sun` | `strength`、`angle` |

所有灯都有 `location` 和 `color`。有方向的灯用 `look_at`（看向一个点，上方保持 +Z）
或 `rotation`（欧拉角）二选一。

## 相机

```json
{"id": "main", "location": [0, -2.3, 0.3], "look_at": [0, 0, 0.13], "lens_mm": 45}
```

`look_at` 与 `rotation` 二选一。其余字段：`projection`（`perspective` /
`orthographic`）、`lens_mm`、`sensor_width_mm`（传感器宽度，水平适配）、
`ortho_scale`、`clip_start`、`clip_end`、`shift`。

## 渲染

| 字段 | 默认 | 说明 |
|---|---|---|
| `camera` | 必填 | 通过哪台相机渲染 |
| `resolution` | `[1280, 720]` | 宽、高（像素） |
| `engine` | `cycles` | `cycles`（路径追踪）、`eevee`（实时，需要 GPU 或软件 OpenGL）、`workbench`（预览着色） |
| `samples` | `64` | 每像素采样数 |
| `denoise` | `true` | Cycles 降噪 |
| `device` | `auto` | `auto` 有可用 GPU 就用 GPU |
| `seed` | `0` | 固定采样种子，保证可复现 |
| `view_transform` | `agx` | 色调映射：`agx`、`standard`、`filmic`、`khronos_pbr_neutral` |
| `exposure` | `0` | 曝光（档） |
| `transparent_background` | `false` | 背景透明 |

`render_scene` 的 `preview` 质量档把分辨率减半、采样封顶 16，`final` 按场景原样渲染。

## 校验结果

`validate_scene` 返回全部问题，每条都有稳定的 `code`、指向字段的 `pointer`、
`message` 和可能的 `hint`。例如：

```json
{"code": "spec.invalid_parameter", "severity": "error",
 "pointer": "/objects/1/geometry/neck_at",
 "message": "vessel: require 0 < belly_at < neck_at < 1"}
```

警告（`severity: "warning"`）不阻止渲染：`spec.scene_unlit`（没有任何光）和
`spec.empty_scene`（没有可见物体）。全部错误码见 [错误码](错误码.md)。
