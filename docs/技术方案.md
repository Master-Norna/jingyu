# 技术方案

> 本文是方案的当前版本（2026-09-26）。已定的决定见 [决策记录](决策记录/README.md)，
> 现有实现见 [架构](架构.md)。

## 定位

景语是一套给模型使用的生图工具与工作流：可控、一致、可编辑。接入的模型自带视觉能力，
它写场景、看图、指出问题、改场景、再渲染。

核心判断：

1. **生成器 = 三维场景 + 虚拟相机。** 光影、透视和遮挡由渲染器物理地保证同源，全局统一
   有了地基。不接扩散模型，保持轻量。
2. **收集生成器，不收集资产。** 几何算子和材质族像音符一样有限、可组合、带参数；一件
   器物是一行参数。图像的好坏主要取决于构图、光和色彩，而不是物体种类的多少。
3. **可编辑、可定位比一次出好图更重要。** 模型知道不对劲却说不出哪里不对时，只需要指出
   位置，工具把位置翻译成场景里可以修改的字段。
4. **立宪先行。** 视觉宪法用来提问，保证多轮迭代不跑题；不作为验收理由。

## 工作流

```
画面意图 ─→ 场景描述 ─→ 校验 ─→ 预览渲染 ─→ 看图（整体、眯眼、明暗、镜像、比较）
                ↑                                   │
                └──── 改参数 ←── 定位 / 布局 / 减法审查 ←┘
                                                    │
                                              正式渲染（final）
```

每次渲染都是新的不可变候选，随时可以回到任何一版比较。

## 同级工具

| 工具族 | 作用 | 状态 |
|---|---|---|
| 场景描述与校验 | 唯一事实来源，问题带 JSON Pointer | 第一波完成 |
| 几何算子 | 基本体、旋转体、器皿 | 第一波完成首批 |
| 材质族 | 陶瓷、玻璃、金属、塑料、Principled | 第一波完成首批 |
| Blender 封装与渲染桥 | bpy 二次封装，隔离进程渲染 | 第一波完成 |
| 看图与定位 | 视图、ID 遮罩定位、布局统计 | 第一波完成 |
| 风化层 | 磨损、积尘、氧化、指纹、边缘磨圆：照片感的来源 | 下一波 |
| 纹理工具 | 经典图形学算法：程序噪声、样例合成、从颜色推导法线与粗糙度、无缝平铺 | 规划中 |
| 风格预设 | 风格绘画：色阶着色、轮廓线、笔触与纸张后处理 | 规划中 |
| 画面宪章 | 一组作品的身份内核：主体、构图骨架、色彩基调、光的情绪、画风 | 规划中 |
| 硬性失败检测 | 穿插、悬空、主体出画或被完全遮挡 | 规划中 |
| CC0 资产补缺 | 人物等有机体 | 最后 |

纹理和后处理只用经典图形学算法，CPU 可跑；神经网络算法即使很小，也会把权重和推理环境
带回来，与轻量的前提冲突，如确有必要只作为可选插件。

## 推进顺序

1. **第一波（已完成）**：工程规范、纯核心、生成器框架与首批几何算子和材质族、场景描述、
   Blender 封装与隔离渲染、不可变候选与 ID 遮罩、看图与定位工具、CLI 与 MCP、测试与 CI、
   视觉宪法 v0.1。验收：同一个器皿函数、八行参数复刻八件器物。
2. **第二波：风化层。** 以参数化的方式给表面加上时间：磨损、积尘、氧化与锈、水渍、
   指纹、边缘磨圆和细微的形变。它决定照片感。
3. **第三波：构图与光。** 相机与布光的辅助（按取景意图求相机、常见布光方案），画面宪章，
   硬性失败检测。
4. **第四波：风格绘画。** 风格预设与后处理，和纹理工具共用算法。
5. **之后**：更多几何算子（挤出、扫掠、布尔、散布）、CC0 资产补有机物、逼真路线。

## 风险

- **干净的生成器输出像产品渲染。** 这是风化层要解决的；在它到来之前，金属等材质在
  单调环境里会显得平（例如铜在白色台面前偏粉）。
- **题材边界。** 有机体难以参数化，靠后续资产补缺；第一阶段选题以器物、建筑、静物、
  风景为主。
- **渲染耗时。** CPU 路径追踪的正式图在分钟级；预览档（半分辨率、16 采样）保持在秒级，
  迭代主要用预览。
