# ADR-0001 用三维场景加虚拟相机生成图像

- 状态：已采纳（2026-09-26）

## 背景

景语要让自带视觉能力的模型通过工具直接生图，并且结果可控、可编辑、风格一致。
扩散模型出图快，但难以精确修改某一处，也难以保证多张图之间光、空间和镜头统一；它还
带来沉重的权重和推理环境。

## 决定

生成器是 Blender 三维场景加虚拟相机。不接扩散模型，保持轻量。需要的纹理处理用经典
图形学算法（程序噪声、样例合成、从颜色推导法线与粗糙度等），封装成与 Blender 封装
同级的工具。长期目标是尽可能逼真，第一阶段先做到风格绘画。

## 后果

- 光影、透视、遮挡由渲染器物理地保证同源，这是全局统一的地基（宪法 J1.05）。
- 每个像素都能追回到场景里的某个物体，定位和局部修改成为可能。
- 题材受限于能搭出什么：人物等有机体是难点，留给后续的 CC0 资产补缺（ADR-0002）。
- 需要 Blender 运行时；EEVEE 和 Workbench 还需要 GPU 或软件 OpenGL。
