# ADR-0014 风格预设与画面宪章

- 状态：已采纳（2026-09-26）

## 背景

技术方案定过：长期目标是逼真，第一阶段先做到风格绘画；一组作品还需要一个“身份内核”
让它们看起来属于同一个系列。两件事都还没有落地。前提仍然是轻量，不接神经网络。象生的
教训也仍然有效：给模型看的数字一旦能被达到，就会被当成目标去凑。

## 决定

- **风格预设是渲染之后的一道后处理**（`style.py`），写在场景的 `render.style` 里，所以
  同一场景总得到同一张画：`ink`（压平的颜色、沿边缘的墨线、纸纹）、`watercolor`（柔化的
  淡彩、边缘加深、颜料在纸纹里沉淀）、`oil`（Kuwahara 滤波做出笔块，画布纹理）、`cel`
  （明暗硬分几档、粗描边）。全部是经典图像运算，Pillow 实现。
- **线条来自场景**：描边取自精确 ID 遮罩上物体与部件的交界，再加上明暗的剧烈变化，所以
  线跟着真实的形状走，不会画在阴影的柔边上。
- **照片渲染保留下来**：风格化后 `image.png` 是画，原图存为 `render.png`，`view_candidate`
  的 `render` 视图可以看。曝光检查在上风格之前做。
- **画面宪章**（`charter.py`，`jingyu.charter.v1`）是工作区里的一个 JSON 文件：主体与主体
  物体、构图骨架（三分、居中、黄金分割、对角线）、主体大小、色板、明暗调子、对比、光的
  情绪、风格。`check_charter` 测量一次渲染的主色、明暗调子、对比和主体位置，把每一处
  不同写成一个问题；没有分数、没有通过线。

## 后果

- 同一场景可以出一张照片和一张画；风格只影响图像，不影响定位、布局和光照诊断。
- 纸纹和画布纹理由确定性的噪声生成，风格化是可复现的。
- 宪章与视觉宪法一样只用来提问；它给出的测量（色差、调子分档）是定位差异的事实，不是
  验收标准。
- 风格是整图的后处理，不能只画一部分；逐物体的风格（例如只给人物描边）留待以后。
