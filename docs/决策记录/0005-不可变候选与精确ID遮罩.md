# ADR-0005 不可变候选与精确 ID 遮罩

- 状态：已采纳（2026-09-26）

## 背景

迭代时需要回到之前的版本比较，需要知道一张图是怎么来的，也需要让模型“指一下”就能找到
要改的东西。

## 决定

- 每次渲染产生一个新的候选目录，发布后不再修改；回执记录场景哈希、渲染参数、运行时和
  每个文件的 SHA-256。
- 每个候选附一张精确 ID 遮罩：单独用 Cycles 渲一遍，1 采样、极窄像素滤波、Raw 视图
  变换、不抖动，每个像素的 RGB 编码一个物体序号，背景透明。
- 定位工具把像素、归一化坐标或框翻译成物体 id、材质 id 和它们的 JSON Pointer。

## 后果

- 模型只需要指出位置，不需要说出原因，就能拿到可编辑的对象。
- 减法审查（`hide`）和候选比较成本低。
- 工作区会累积候选；清理由用户决定，工具不删除候选。
