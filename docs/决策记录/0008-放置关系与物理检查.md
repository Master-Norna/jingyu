# ADR-0008 放置关系与物理检查

- 状态：已采纳（2026-09-26）

## 背景

同一次实测里，挪一扇窗要改 7 处坐标，挪一组器物要改 5 处；橙子陷进碗里、罐子离桌面
悬空 2 厘米，都要模型自己心算几何才能发现和改正。一轮下来耗了很多 token，注意力却没花在
画面上。根子在于场景里只有绝对坐标，东西之间的关系没有地方写。

## 决定

- 场景加**编组**（`groups`，可嵌套，统一缩放）和 `parent`：一起动的东西放进一个编组，
  挪编组就行。
- 物体加 `rest_on`：保持世界 x、y，高度由景语求出，落在支撑物正下方最高的表面上。
- 放置解析放在纯核心（`jingyu/placement.py`），主机和 Blender worker 调用同一份代码，
  两边结果完全一致；worker 直接写世界矩阵。
- 穿插与悬空由景语检查，作为带修改提示的警告返回；出画和曝光在渲染后检查，写进回执。
- 场景修改用 `edit_scene`（JSON Patch 加 `merge`，`@<id>` 按 id 寻址），不再整份重写。

## 后果

- 校验要生成并变换全部网格，一个十几件物体的场景大约多花 0.5 到 1 秒，换来的是模型不用
  再算几何。
- 物理检查只看顶点、只沿坐标轴测距，是近似：很薄的物体侧面贴得很近时深度会被高估，边与
  边相交而没有顶点入内时查不出。它们是警告，不是错误。
- 编组只允许统一缩放，这样灯和相机的朝向、物体的矩阵在 Blender 里都能精确表示。
