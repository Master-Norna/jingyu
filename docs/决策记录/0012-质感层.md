# ADR-0012 质感层：程序纹理、风化与空气

- 状态：已采纳（2026-09-26）

## 背景

技术方案早就判断“干净的生成器输出像产品渲染”，两次重测也都提到：桌子像塑料，墙像
石膏模型，铜在白台面前偏粉，“有空气感”只能靠柔和的明暗过渡勉强表达。照片感主要来自
表面上的时间和材料自身的纹理，以及空气里的尘雾。前提仍然是轻量：不接神经网络，不引入
资产文件。

## 决定

- **配方里加入标量场、图层和凹凸**（`materials/recipe.py`）。标量场是表面上 0 到 1 的
  量，来自经典程序纹理（分形噪声、脊线噪声、Voronoi 细胞与裂缝、年轮与条带）或形状本身
  （朝上程度、凸边、凹处、离底部的高度）。图层在场为 1 的地方换上别的颜色、粗糙度、金属度；
  凹凸按场推出表面起伏。全部是数据，worker 翻译成着色节点（`blender/shading.py`）。
- **三维实体纹理，不用贴图**：场读物体自身的坐标（米），所以不需要 UV 展开、没有接缝、
  永不平铺，纹理大小就是真实尺寸。“从颜色推导法线和粗糙度”用同一个场同时驱动颜色、粗糙度
  和凹凸来实现。
- **新的材质族**：`wood`（沿轴向的年轮、导管、清漆）、`stone`（大理石、花岗岩、混凝土）、
  `fabric`（织纹与绒光）、`peel`（果皮的毛孔与红晕）。原有的族加上纹理参数：陶瓷的铁斑和
  坯体颗粒、塑料的表面肌理、金属的拉丝与氧化（铁生锈，铜在凹处泛绿）。纹理参数为 0 时
  结果与此前完全相同。
- **风化层写在材质条目上，与材质族无关**：`weathering` 的磨损（凸边露底）、积尘（朝上的
  面）、污垢（凹处和底部）、水渍（矿物圈）、指纹（光滑面上的哑光斑），都顺着形状生长。
- **空气是环境族的参数**：`mist`、`mist_color`、`mist_glow` 在场景周围生成一团有边界的
  散射介质，让窗口的阳光显出光柱、远处变柔。介质有边界是必要的：无限大的介质会把从无穷远
  来的阳光和窗外的天空全部吞掉。它不进入 ID 遮罩和光照诊断。
- **器皿的手工形变**：`vessel` 的 `wobble` 让器物略微不圆、微微倾斜，内外壁一起动，底仍然
  平放在地上。
- 暂不做样例合成和图像平铺：它们需要样图，也就是资产；三维程序纹理不需要平铺。

## 后果

- 同一张桌子可以是新的、旧的、落了灰的，只差几个参数；风化让渲染第一次读得像照片。
- 凸边和凹处用环境光遮蔽节点测量：Cycles 的 OptiX 设备第一次遇到它时要现场编译专用
  内核（本机约四分钟），之后缓存，不再影响渲染时间。
- 一种材质只有一个纹理方向（例如木纹沿 x）；同一物体的不同部件要不同方向时，给部件
  指定两种材质。
- 主机不模拟纹理：颜色测量仍以材质的基础颜色为“作者给的颜色”。
