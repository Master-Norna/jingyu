# ADR-0003 场景描述是唯一事实来源

- 状态：已采纳（2026-09-26）

## 背景

模型就算知道图不对劲，也可能说不出哪里不对。要让修改有抓手，图像必须能追回到一份可以
读、可以比较、可以局部修改的描述；而描述的格式如果和生成器各写一份，迟早会漂移。

## 决定

- 一张图由一份声明式 JSON 场景描述（`jingyu.scene.v1`）决定，渲染只消费它的规范化结果。
- 场景 Schema、默认值、工具目录和文档都从生成器的参数声明推出，不手写第二份。
- 校验分严格解析、Schema、语义三步；问题一次报全，每条带 JSON Pointer 和提示。
- 不提供执行任意 bpy 脚本的逃生口；需要新能力时加生成器。

## 后果

- 新增算子或材质族不需要改 Schema 代码。
- 场景可以用内容哈希标识，候选之间可以比较场景差异。
- 表达力受生成器集合限制，这是有意的：限制换来可追溯。
