# ADR-0013 自由形状与自然生成器

- 状态：已采纳（2026-09-26）

## 背景

旋转体和装配覆盖了器物和家具，但场景常常还需要一块 L 形台面、一个杯子把手、一根管子、
一地卵石，以及户外的地形、岩石、树和草。Norna 提出过自然景观的方向。技术方案也列了挤出、
扫掠、布尔和散布。

## 决定

- **挤出**（`extrude`）：任意简单多边形向上拉伸，可收分；凹多边形用耳切法三角化，自相交
  时报错。
- **扫掠**（`sweep`）：沿过若干点的光滑曲线（Catmull-Rom）生成圆管，可由粗到细；截面用
  平行移动的标架，转弯时不扭。挤出和扫掠保留给定的坐标，不移到“立在原点上”：把手的路径
  就写在杯子身上的位置，配合 `parent` 使用。
- **散布**（`scatter`）：把一个几何调用的结果按泊松圆盘撒在矩形或圆形区域里，每件随机
  转向、缩放、倾斜；参数 `item` 本身是一个几何调用，几何联合 Schema 因此带有自己的
  `$id`，参数表可以引用它。
- **自然生成器**：`terrain`（分形高度场，可带山脊，封成立在原点上的实体）、`rock`（立方
  球加噪声位移，底部压平）、`tree`（带分枝的树干加叶簇，或层叠下垂的针叶；树干和叶子
  各有默认材质）、`grass`（成千片草叶）；材质族 `water`。全部由纯核心里确定性的值噪声
  生成，主机侧放置和物理检查看到的就是渲染的形状。
- **布尔运算仍不做**：理由见 ADR-0011。

## 后果

- 同一个种子永远得到同一块岩石、同一棵树；换种子得到同类的另一个。
- 这些网格在主机上用纯 Python 生成，大场景的构建会慢几秒（地形分辨率、草的密度是主要
  开销）。
- 树是远景尺度的：叶子是成团的形体，不是一片片叶子；近景的植物仍然要靠后续的资产补缺。
- `examples/scenes/lakeside.json` 是这些生成器的冒烟示例，不是画面范例。
