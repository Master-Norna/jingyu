# ADR-0006 立宪先行

- 状态：已采纳（2026-09-26）

## 背景

生图是分布性任务：一张图最常失败在全局视觉不统一，轮不到细节纹理。好的提示词不难，
难在不过拟合、处处适用，还能带来启发。tianlai 用宪法式迭代保证了质感统一、迭代不跑题。

## 决定

- 《景语视觉宪法》v0.1 作为可选的思想资源，按条款 id 有界查询（一次最多 12 条）。
- 条款用来提问，不作为验收理由；机器能判定的硬性失败放进校验与检测。
- 条款要跨端成立：同时适用写实、风格绘画和抽象构成（J0.12）。

## 后果

- 宪法文本在 `docs/视觉宪法/` 和包内各一份，测试保证逐字节一致。
- 工具流程（先看整体、眯眼、看明暗、减法审查）直接对应宪法里的追问。
